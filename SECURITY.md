# Reporting a security problem

Please don't open a public issue for a vulnerability. Use GitHub's **Report a vulnerability** button on this repository's Security tab, which reaches the maintainer privately. Include what you found, how to reproduce it, and what it could expose.

You'll get a reply within a week. Fixes ship as a new release with a note in the changelog. Anyone running a server updates with `sudo jobsctl update`.

The security model and its known limits are in [docs/security.md](docs/security.md).
