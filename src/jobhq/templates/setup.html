1. Connect Claude

Claude does the reading, scoring and writing. Use either:

  • Your own Claude Pro or Max plan (Pro is $20 a month). Your plan is signed in once on the server, through Claude's own sign-in screen; whoever runs your server does this with you (see the end of this page). Job Search HQ never sees your Claude password or token. Then choose it in Settings.
  • An Anthropic API key (pay per use). Create one at console.anthropic.com → API keys, add a few dollars of credit, and paste it in Settings. Settings has a monthly cap.

3. Set up job alerts

Job sites email you new postings; Job Search HQ reads those emails and adds the roles for you. No scraping.

LinkedIn

  1. On LinkedIn, search Jobs for a title you want (for example "Medical Assistant", "Store Manager" or "Data Analyst") and set filters: location, remote, date posted.
  2. Turn on Set alert at the top of the results. Choose Daily and Email.
  3. Repeat for each title. Manage them later under Jobs → Job alerts.

Indeed

  1. Search on Indeed with your title and location, then choose Get new jobs for this search by email.

Alerts go to the Gmail address you connected. If your LinkedIn uses another address, add a Gmail filter to forward alerts.

4. Notifications on this device

Get reminders, interview days and inbox news as notifications. Do this on each device you use. On an iPhone or iPad, first tap Share → Add to Home Screen, then open Job Search HQ from the home screen. On a Chromebook or computer, Chrome's address bar has an Install icon that makes it an app.

Blocked by mistake, or using another device? Device-by-device steps.

5. Watch company job boards

Many companies post jobs on Greenhouse, Lever or Ashby, which publish open job lists. Add the companies you want on the Inbox page, and new matching roles appear each morning.

For whoever runs your server

You don't need this part to use Job Search HQ; it's for the person who set up the server.

Claude plan sign-in

In Cloud Shell, connect to the server and run sudo jobsctl claude-login {{ ctx.config.instance_name }}. Claude Code shows a link: the job seeker opens it, signs in to their own Claude account, and pastes the code back.
